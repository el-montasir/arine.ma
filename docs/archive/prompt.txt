19. CHECKOUT SUBMISSION
The current button currently does:

showToast()

Replace that behavior.
The new flow must be:

1. Validate form.
2. Check cart is not empty.
3. Disable submit button.
4. Show loading state.
5. Send POST /api/orders.
6. Wait for backend response.
7. If successful:
      clearCart()
      save returned order number
      navigate to /order-success
8. If failed:
      DO NOT clear cart
      DO NOT lose form data
      show an error
      enable button again
Never clear the cart before the server confirms the order.
